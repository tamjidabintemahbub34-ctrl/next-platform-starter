# Excel Lead Tracker & Data Management

**Project type:** Independent practice project  
**Training stage:** Day 2 — Professional Excel & Google Sheets  
**Service demonstrated:** Spreadsheet organization, sorting, filtering, data cleaning, quality checks and reporting.

## Project objective
Prepare a client-ready lead database that is easy to review, filter, maintain and hand over.

## Planned workbook structure
- `START HERE` — project overview and usage instructions
- `LEAD DATABASE` — structured lead records
- `SOURCE REGISTER` — source URLs and verification evidence
- `QUALITY CHECK` — blanks, duplicates and data-quality review
- `SUMMARY` — totals and status counts

## Skills covered
- Sorting complete records without separating related columns
- Filtering records by relevant fields and status
- Cleaning inconsistent text and spreadsheet data
- Using formulas for counts and quality checks
- Preparing a clear client handover
