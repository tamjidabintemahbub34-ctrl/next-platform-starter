**Role focus:** E-commerce and Data Support Specialist  
**Tools planned:** Microsoft Excel / Google Sheets; Shopify concepts  
**Project type:** Independent practice sample, not a paid client project.

## Project overview

This portfolio project is designed to demonstrate an organized e-commerce operations and reporting workflow in one Excel workbook. The planned workbook contains five connected sheets:

1. **Product_Master** — product names, categories, variants, SKUs and prices.
2. **Inventory_Tracker** — opening stock, stock received, stock sold, available stock and low-stock checks.
3. **Order_Management** — order IDs, dates, products, quantities and order/payment/fulfillment status.
4. **Sales_Analysis** — revenue, units sold, product performance and sales summaries.
5. **Ecommerce_Dashboard** — key metrics and business insights in one view.

## Skills demonstrated

- Product and variant data organization
- SKU structure and duplicate checking
- Inventory tracking and stock reconciliation
- Order status tracking
- Spreadsheet formulas, filtering and PivotTables
- Sales and inventory reporting
- KPI dashboard planning and business communication
